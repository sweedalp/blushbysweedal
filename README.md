# blushbysweedal

Enchanted magazine site for fashion & beauty creator **blushbysweedal**.

## Run locally

```bash
cd D:\blushbysweedal\site
npm install
npm run dev
```

Open the URL shown in the terminal (usually http://localhost:5173).

## Stack

- React + Vite
- Inline styles in components
- Keyframe animations in `src/index.css`
- Media in `public/media`
